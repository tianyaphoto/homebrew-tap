# tianyaphoto/tap

Homebrew 安装源 · Homebrew tap

```bash
brew install --cask tianyaphoto/tap/fanyi
brew install --cask tianyaphoto/tap/voicewriter
```

| Cask | App |
|---|---|
| `fanyi` | [翻译神器 Fanyi](https://github.com/tianyaphoto/fanyi)：macOS 菜单栏翻译工具 · menu bar translator |
| `voicewriter` | [VoiceWriter](https://voice-writer.com)：macOS 语音输入，按住快捷键说话，文字出现在光标处 · hold-to-dictate voice input |
